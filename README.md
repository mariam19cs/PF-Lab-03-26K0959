## Introduction

This lab introduces the basic use of GitHub and fundamental concepts of the C programming language. It focuses on creating repositories, working with branches, commits and pull requests, as well as understanding C data types, input/output functions, format specifiers, escape sequences and precision formatting.

## Objectives

1. To create and manage a GitHub repository.
2. To understand branches, commits and pull requests.
3. To learn basic Markdown documentation.
4. To understand different C data types.
5. To practice C input and output functions.
6. To use format specifiers and escape sequences.
7. To understand floating-point precision.

## C Topics Covered

* Variables
* Data Types
* Input and Output
* Format Specifiers
* Escape Sequences
* Precision
* `scanf()`
* `printf()`
* `getchar()`
* `putchar()`
* `fgets()`
* `puts()`
